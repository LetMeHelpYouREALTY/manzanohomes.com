# Manzano Homes

Next.js 15 App Router site for Manzano Peak / Las Vegas 89121 real estate.

- **Stack:** Next.js 15, React 19, TypeScript, Tailwind CSS
- **Deploy:** Vercel (`iad1`)
- **Listings:** RealScout web components (`em.realscout.com` + `www.realscout.com` in CSP)

```bash
pnpm install
pnpm dev
```

Production build: `vercel build` (or `pnpm build` locally).
